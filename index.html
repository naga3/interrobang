‽ Interrobang (びっくりはてな言語) 仕様書

Interrobang (‽) は、文章中の感嘆符（！）と疑問符（？）のみを抽出し、その他の文字を完全に無視する難解プログラミング言語（Esoteric Language / 怪文書生成系言語）です。UTF-8規格に完全対応しています。

1. 構文規則 (Syntax Rules)

  • ！ または !（全角・半角）は 0 を表します。
  • ？ または ?（全角・半角）は 1 を表します。
  • 上記以外の文字（ひらがな、カタカナ、漢字、アルファベット、空白など）は すべて無視 されます。

2. 実行モデル & UTF-8 対応 (Execution Model)

  • プログラムは行（改行）ごとに1ステップずつ処理されます。
  • 各行に含まれる ！ と ？ を左から順に取り出して2進数ビット列を構成します。
  • UTF-8 マルチバイト処理:
    • 行のビット長が8の倍数の場合、各8bitをバイト列としてUTF-8デコードします。
    • 1行1文字形式: 日本語のひらがな・漢字（3バイト = 24bit）や絵文字（4バイト = 32bit）を1行にまとめて記述できます。
    • 1行1バイト形式: 1行を8bitとし、複数行にわたって1文字のUTF-8バイト列をストリーム構成することも可能です。
  • UTF-8バイト列として解釈できないビット長（例: 14bitなど）の場合は、直接 Unicodeコードポイント としてフォールバック解釈されます。
  • 記号を含まない行（コメントや空行）は出力されず無視されます。

3. UTF-8 バイト長の対応一覧

文字種別 UTF-8 バイト数 行内のビット数 例
ASCII (英数・基本記号) 1 Byte 8 bit H = 01001000
ラテン拡張・ギリシャ・キリル 2 Bytes 16 bit Ω = 11001110 10101001
日本語 (ひらがな・カタカナ・漢字) 3 Bytes 24 bit あ = 11100011 10000001 10000010
絵文字・特殊文字 4 Bytes 32 bit 🎉 = 11110000 10011111 10001110 10001001

4. 名称の由来

「Interrobang（インテロバング）」とは、感嘆符（！）と疑問符（？）を重ね合わせたタイポグラフィ記号「‽」のことです。驚きと疑問を同時に叫ぶ感情の爆発を表現する文字として、1962年に名付けられました。
